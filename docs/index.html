See it before it happens

Each new name shows next to the old one as you type. Names that clash, or that would break on another system, are marked before you rename.

Every rename can be undone

Each rename goes into History. Undo puts the old names back, even after you restart Alterix. Replaced files go to the system trash.

Stays on your computer

Works offline. No accounts, no tracking, no adverts. It only goes online when you ask it to check for updates.

Every renaming tool in one clear window

Add the steps you need. Alterix shows the result while you work.

Messy names, tidied in a few steps

Problems caught early

Clashing names and names that break on another system are marked before you rename.

Filters

Show only the files you want with masks such as *.jpg !*_old.*.

Subfolders and hidden files

Include files in subfolders, hidden files, or the folders themselves.

Tick what changes

Untick any item to leave it exactly as it is.

Move or copy

Send renamed files to another folder in the same run.

Dates and attributes

Set file dates and attributes while you rename.

Presets

Save your steps as a preset and open it again later.

Presets that load themselves

A preset named _autoload.alterix loads when you open its folder.

Rename from a list

Import old and new name pairs from a file or the clipboard.

Regular expressions

Match and replace with patterns when plain text isn't enough.

Rename one by hand

Select an item and press F2 to rename just that one.

Open in Alterix

Add it to your file manager's menu in Settings. Off until you add it.
